## 🚀 Local Setup & Preview

To run this project locally without external dependencies:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Bajazz0703/Jhastter-Rollon-Personal-CV.git
   cd Jhastter-Rollon-Personal-CV
   ```

2. **Open in browser:**
   - Double-click `index.html` to open it directly in your web browser.
   - Or start a local server:
     ```bash
     # Using Python
     python -m http.server 8080
     # Using Node.js (npx)
     npx serve .
     ```
   - Navigate to `http://localhost:8080` in your web browser.
